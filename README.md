🚀 Installation


Clone Repository


git clone https://github.com/Supritam-005/TASK-MANAGER-FULL-STACK-.git

🔧 Backend Setup


cd server


npm install


npm start

💻 Frontend Setup

cd client
npm install
npm run dev


🌐 Environment Variables
Create a .env file inside the server folder:


PORT=5000


MONGO_URI=your_mongodb_connection


JWT_SECRET=your_secret_key
